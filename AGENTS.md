## Import sorting

`sort-imports` sorts by syntax type (`none` → `all` → `multiple` → `single`), then by first member/alias name (case-sensitive). See [Oxlint sort-imports](https://oxc.rs/docs/guide/usage/linter/rules/eslint/sort-imports.html).
